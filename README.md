# Login Test

Um simples portal de teste de autenticação para a plataforma da Viajant, caso a plataforma principal der erro.

## Por que deixei isso Open Source?
Porque, basicamente, é o que eu chamo de "Login Up", pois eu não vou precisar colocar TUDO no código principal da Viajant, se não eu poderia BAGUNÇAR tudo e ainda isso ia virar um desastre.
